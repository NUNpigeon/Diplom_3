# Автотесты для UI веб-приложения Stellar Burgers
(Дипломный проект) Diplom_3


## Описание проекта
Данный проект содержит автоматические UI-тесты для веб-приложения Stellar Burgers

**Основной сайт:** [Stellar Burgers](https://stellar-burgers.example.com) 


**Цель:** Автоматизация UI-тестов веб-приложения Stellar Burgers с использованием подхода Page Object, проверка функциональности в браузерах Google Chrome и Яндекс Браузер, генерация отчётов с помощью Allure.

## Задание
Опиши элементы, которые будешь использовать в тестах, с помощью Page Object.
Протестируй функциональность в Google Chrome и Яндекс Браузере.
Подключи Allure-отчёт.



## Реализована функциональность

####  Регистрация

*   Успешная регистрация нового пользователя
*   Проверка ошибки при вводе некорректного пароля (минимальный пароль —шесть символов)

#### Вход в аккаунт

Тестируются 4 способа входа:

*   через кнопку «Войти в аккаунт» на главной странице;
*   через кнопку «Личный кабинет»;
*   через кнопку в форме регистрации;
*   через кнопку в форме восстановления пароля.

#### Раздел «Конструктор»

*   проверка работоспособности переходов к разделам:
    *   «Булки»;
    *   «Соусы»;
    *   «Начинки».

## 3. Окружение для тестирования

*   Браузеры: Google Chrome, Яндекс Браузер.

*   Инструменты:
    *   Selenium WebDriver (для автоматизации действий в браузере);
    *   Page Object Model (для структурирования кода тестов);
    *   Allure Report (для генерации отчётов о тестировании);
    *   Java/TestNG/JUnit (на выбор, в зависимости от стека проекта).

## 4. Интеграция с Allure Report

Для генерации Allure-отчётов необходимо выполнить следующие шаги:

*   Добавить зависимости Allure в `pom.xml` (если используется Maven).
*   Настроить слушатель Allure в тестовом фреймворке (например, `AllureTestListener` для TestNG).
*   Запускать тесты с генерацией результатов Allure:

    ```bash
    mvn test
    ```
